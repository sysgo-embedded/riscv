The RISC-V platform is well supported by SYSGO, e.g. by its PikeOS hypervisor and ELinOS Embedded Linux, see e.g. [Shel26].

The folder "ipcard" contains IP cards for RISC-V developments in the TRISTAN, ISOLDE and REBECCA projects referenced by the Unified RISC-V IP Access Platform (https://openhwfoundation.github.io/uap/).
